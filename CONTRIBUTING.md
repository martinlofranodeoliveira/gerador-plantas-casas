# Contribuir

Use Node.js 22.12+ e `npm ci --ignore-scripts`. Execute `npm test` e
`npm run build`. Comece uma issue com problema, comportamento esperado e JSON
fictício reproduzível. Explique alterações de medidas, eixos e semântica de
exports; inclua testes de borda. Alterações em unidades não podem divergir entre
planta, 3D e relatórios. Inclua revisão em tela pequena e teclado quando possível.

Preserve autoria/licenças. Não inclua fotos, endereços, plantas pessoais, `.env`,
chaves, bancos ou dados de clientes. Não use a API paga em testes automáticos.
Contribuições propostas para este código seguem MIT, respeitadas licenças de
terceiros. Uma PR útil pode conter uma mudança completa; contagem de commits
não é um critério de qualidade.
